# Klar til start som IT-konsulent

Et forløb på 7 dage, der skal give dig sproget og de mentale modeller, så du kan følge med fra første dag i et IT-projekt.

Målet er **ikke**, at du kan det hele. Målet er, at du ved, hvad folk taler om i standup og refinement, og at du ved, hvad du skal spørge om eller google. Resten lærer du på projektet og i Netcompanys eget onboarding-forløb.

## Sådan bruger du forløbet

- Én tutorial om dagen, ca. 2–4 timer.
- Lav øvelserne. Du lærer mere af at skrive kommandoerne selv end af at læse om dem.
- Tutorial 01 lærer dig Git. Derefter afleverer du dine noter og løsninger som **pull requests** til det her repo, præcis som du kommer til at gøre på jobbet.
- Hver tutorial har en liste med videoer og interaktivt materiale. Den står ved hver tutorial med anvisninger om, *hvornår* du skal se hvad.
- Fra dag 1b bruger du **Claude Code som tutor**. Kør `claude` i repoet, og spørg løs. Den er sat op (i `CLAUDE.md`) til at give hints frem for svar.
- Hver tutorial slutter med en ordliste. Alle ordene bliver samlet i [ORDLISTE.md](ORDLISTE.md).

Forløbet er på dansk, men fagudtrykkene står på engelsk, fordi det er dem, du kommer til at høre.

## Plan

| Dag | Tutorial | Kort fortalt |
|-----|----------|--------------|
| 0 | [Gør din Mac klar](00-opsaetning/README.md) | Claude-konto, Ghostty-terminal, VS Code-opsætning, tjek af Git og Python |
| 1 | [Terminal og Git](01-terminal-og-git/README.md) | Hvor koden bor, og hvordan et team arbejder i den samme kode |
| 1b | [AI som arbejdsredskab](01b-ai-som-arbejdsredskab/README.md) | LLM'er, Claude Code som din tutor, og hvad du må og ikke må som konsulent |
| 2 | Hvordan et system hænger sammen | Klient/server, HTTP, REST, JSON. Du bygger et mini-API i Python |
| 3 | Data: SQL og datamodellering | Fra `pandas` til SQL, tabeller, nøgler, ER-diagrammer og normalisering |
| 4 | At læse kode i Java/C# | Typer, klasser, interfaces og tests, så du kan læse enterprise-kode |
| 5 | Fra behov til løsning | Krav, user stories, acceptkriterier, Scrum, Jira, testniveauer og miljøer |
| 6 | Drift og cloud | Docker, containere, Kubernetes i overblik, Azure/AWS og logs |
| 7 | Sikkerhed og konsulentlivet | Login, OAuth2/OIDC, JWT, MitID/NemLog-in, GDPR, udbud og kunderelationer |

## Det skal du have

Start med [dag 0](00-opsaetning/README.md). Den gør din Mac klar med Claude-konto, Ghostty, VS Code, Git og Python. Derudover skal du have:

- En gratis konto på [github.com](https://github.com).
